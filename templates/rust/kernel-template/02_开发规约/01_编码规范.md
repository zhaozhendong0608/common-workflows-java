# Rust 编码规范

> 基于 Rust Style Guide 官方规范

---

## 🎯 核心原则

1. **零成本抽象**: Zero-cost abstractions
2. **内存安全**: 编译期保证内存安全
3. **所有权系统**: Ownership, borrowing, lifetimes
4. **显式优于隐式**: 明确的类型和错误处理

---

## 📝 命名规范

### 基本规则
- **snake_case**: 变量、函数、模块
- **PascalCase**: 类型、trait
- **SCREAMING_SNAKE_CASE**: 常量、静态变量

```rust
// ✅ 正确
mod user_service;           // 模块
struct UserProfile {}       // 结构体
trait Drawable {}           // trait
enum Status {}              // 枚举

fn get_user_data() {}       // 函数
let user_name = "John";     // 变量
const MAX_SIZE: usize = 100; // 常量
static GLOBAL_COUNT: AtomicUsize = AtomicUsize::new(0); // 静态变量

// ❌ 错误
mod UserService;            // 应该用 snake_case
fn GetUserData() {}         // 应该用 snake_case
const maxSize: usize = 100; // 应该用 SCREAMING_SNAKE_CASE
```

### 类型命名
```rust
// ✅ 正确 - 类型参数单字母大写
struct Vec<T> { /* ... */ }
trait Iterator<Item> { /* ... */ }

// ✅ 正确 - lifetime 小写单字母
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str { /* ... */ }

// ✅ 正确 - 转换方法命名
impl User {
    fn as_str(&self) -> &str {}      // 借用转换
    fn to_string(&self) -> String {} // 拥有权转换
    fn into_string(self) -> String {} // 消耗自身转换
}
```

## 🔧 语言特性

### 所有权和借用
```rust
// ✅ 正确 - 所有权转移
fn take_ownership(s: String) {
    println!("{}", s);
} // s 在此被 drop

// ✅ 正确 - 不可变借用
fn borrow(s: &String) {
    println!("{}", s);
}

// ✅ 正确 - 可变借用
fn borrow_mut(s: &mut String) {
    s.push_str(" world");
}

// ✅ 正确 - 使用
let s = String::from("hello");
borrow(&s);           // 借用
borrow_mut(&mut s);   // 可变借用
take_ownership(s);    // 转移所有权（s 不再可用）
```

### 错误处理
```rust
// ✅ 推荐 - 使用 Result
fn divide(a: i32, b: i32) -> Result<i32, String> {
    if b == 0 {
        Err(String::from("division by zero"))
    } else {
        Ok(a / b)
    }
}

// ✅ 推荐 - ? 操作符
fn read_file(path: &str) -> Result<String, std::io::Error> {
    let content = std::fs::read_to_string(path)?;
    Ok(content)
}

// ✅ 推荐 - unwrap_or 提供默认值
let value = result.unwrap_or(0);

// ❌ 避免 - unwrap（会 panic）
let value = result.unwrap();  // 仅在确定不会失败时使用
```

### Option 处理
```rust
// ✅ 推荐 - 模式匹配
match user.email {
    Some(email) => println!("Email: {}", email),
    None => println!("No email"),
}

// ✅ 推荐 - if let
if let Some(email) = user.email {
    println!("Email: {}", email);
}

// ✅ 推荐 - map
let uppercase = user.email.map(|e| e.to_uppercase());

// ✅ 推荐 - unwrap_or
let email = user.email.unwrap_or_default();
```

### 迭代器
```rust
// ✅ 推荐 - 使用迭代器而非循环
let doubled: Vec<i32> = vec![1, 2, 3]
    .iter()
    .map(|x| x * 2)
    .collect();

let sum: i32 = vec![1, 2, 3]
    .iter()
    .sum();

let evens: Vec<i32> = vec![1, 2, 3, 4]
    .into_iter()
    .filter(|x| x % 2 == 0)
    .collect();

// ❌ 避免 - 传统循环（除非性能关键）
let mut doubled = Vec::new();
for x in vec![1, 2, 3] {
    doubled.push(x * 2);
}
```

## 🛡️ 类型系统

### 结构体和枚举
```rust
// ✅ 正确 - 结构体
#[derive(Debug, Clone)]
pub struct User {
    pub id: u64,
    pub username: String,
    email: String,  // 私有字段
}

impl User {
    // 构造函数
    pub fn new(id: u64, username: String, email: String) -> Self {
        Self { id, username, email }
    }
    
    // 方法
    pub fn email(&self) -> &str {
        &self.email
    }
}

// ✅ 正确 - 枚举
pub enum Status {
    Active,
    Inactive,
    Suspended(String),  // 带数据的变体
}

// ✅ 正确 - Result 类型别名
pub type Result<T> = std::result::Result<T, Error>;
```

### Trait
```rust
// ✅ 正确 - 定义 trait
pub trait Repository {
    type Item;
    
    fn find(&self, id: u64) -> Option<Self::Item>;
    fn save(&mut self, item: Self::Item) -> Result<()>;
}

// ✅ 正确 - 实现 trait
impl Repository for UserRepository {
    type Item = User;
    
    fn find(&self, id: u64) -> Option<User> {
        self.users.get(&id).cloned()
    }
    
    fn save(&mut self, user: User) -> Result<()> {
        self.users.insert(user.id, user);
        Ok(())
    }
}
```

### 泛型
```rust
// ✅ 正确 - 泛型函数
fn first<T>(list: &[T]) -> Option<&T> {
    list.first()
}

// ✅ 正确 - trait bound
fn print_info<T: Display>(item: T) {
    println!("{}", item);
}

// ✅ 正确 - where 子句
fn complex<T, U>(t: T, u: U) -> i32
where
    T: Display + Clone,
    U: Clone + Debug,
{
    // ...
}
```

## 🛠️ 最佳实践

### 智能指针
```rust
// ✅ Box - 堆分配
let boxed = Box::new(5);

// ✅ Rc - 引用计数（单线程）
use std::rc::Rc;
let shared = Rc::new(5);
let shared2 = Rc::clone(&shared);

// ✅ Arc - 原子引用计数（多线程）
use std::sync::Arc;
let shared = Arc::new(5);

// ✅ RefCell - 内部可变性
use std::cell::RefCell;
let value = RefCell::new(5);
*value.borrow_mut() += 1;
```

### 并发
```rust
use std::thread;
use std::sync::{Arc, Mutex};

// ✅ 正确 - 线程安全
let counter = Arc::new(Mutex::new(0));
let mut handles = vec![];

for _ in 0..10 {
    let counter = Arc::clone(&counter);
    let handle = thread::spawn(move || {
        let mut num = counter.lock().unwrap();
        *num += 1;
    });
    handles.push(handle);
}

for handle in handles {
    handle.join().unwrap();
}
```

### 异步编程
```rust
use tokio;

// ✅ 正确 - async/await
#[tokio::main]
async fn main() {
    let result = fetch_data().await;
    println!("{:?}", result);
}

async fn fetch_data() -> Result<String, reqwest::Error> {
    let body = reqwest::get("https://api.example.com")
        .await?
        .text()
        .await?;
    Ok(body)
}

// ✅ 正确 - 并发执行
let (result1, result2) = tokio::join!(
    fetch_data(),
    fetch_data()
);
```
