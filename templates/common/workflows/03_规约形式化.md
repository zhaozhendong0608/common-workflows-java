# 03_规约形式化

**命令**: `/constraint`

---

## 输入

- 需求分析报告（来自 `/radar`）
- 项目规约（来自 `kernel-template/02_开发规约/`）

---

## 核心步骤

### 1. 读取项目规约

```bash
# 编码规范
cat kernel-template/02_开发规约/01_编码规范.md

# 架构规范
cat kernel-template/02_开发规约/02_架构规范.md
```

---

### 2. 生成约束清单

根据需求和规约，生成 `constraint-checklist.yml`：

```yaml
# 约束清单示例
constraints:
  - id: C001
    type: 编码规范
    rule: 使用 Jackson 序列化
    check: 禁止使用 Gson/FastJSON
    
  - id: C002
    type: 日志规范
    rule: 日志必须是中文
    check: log.info("用户登录成功") ✅
    
  - id: C003
    type: API 规范
    rule: 返回格式统一
    check: 使用 Result<T> 包装响应
```

---

### 3. 保存约束清单

```bash
# 保存到项目内核
mkdir -p kernel-template/constraints
cat > kernel-template/constraint-checklist.yml << 'EOF'
[约束清单内容]
EOF
```

📖 [约束清单模板](../templates/constraint-checklist-template.md)

---

## 输出

- `kernel-template/constraint-checklist.yml` - 约束清单文件
- 约束数量统计

---

## 约束清单结构

```yaml
constraints:
  - id: 约束编号
    type: 约束类型（编码/架构/数据库/API）
    rule: 规则描述
    check: 检查方法
```
