# Python 编码规范

> 基于 PEP 8 (Python Enhancement Proposal 8) 官方规范

---

## 🎯 核心原则

1. **可读性至上**: 代码被阅读的次数远多于编写
2. **显式优于隐式**: Explicit is better than implicit
3. **简单优于复杂**: Simple is better than complex
4. **扁平优于嵌套**: Flat is better than nested

---

## 📝 命名规范

### 模块和包
- **小写 + 下划线**: `my_module.py`, `my_package/`
- **避免使用下划线**: 优先 `mymodule` 而非 `my_module`

### 类
- **PascalCase**: `class MyClass:`
- **异常类**: 以 `Error` 结尾，如 `ValidationError`

### 函数和变量
- **snake_case**: `my_function()`, `my_variable`
- **私有属性**: 单下划线前缀 `_private_attr`
- **强私有**: 双下划线前缀 `__private_attr` (触发名称改写)

### 常量
- **UPPER_SNAKE_CASE**: `MAX_SIZE = 100`

### 示例
```python
# ✅ 正确
class UserProfile:
    MAX_AGE = 150
    
    def __init__(self, name):
        self.name = name
        self._internal_id = None
    
    def get_user_data(self):
        return self.name

# ❌ 错误
class userProfile:  # 应该用 PascalCase
    maxAge = 150    # 应该用 UPPER_SNAKE_CASE
    
    def GetUserData(self):  # 应该用 snake_case
        pass
```

## 📐 代码格式

### 缩进
- **4 个空格**（不使用 Tab）
```python
# ✅ 正确
def my_function():
    if condition:
        do_something()
        do_another()

# ❌ 错误 (2个空格)
def my_function():
  if condition:
    do_something()
```

### 行长度
- **最大 79 字符**（代码）
- **最大 72 字符**（注释/文档字符串）

```python
# ✅ 正确 - 长行折叠
result = some_function(
    arg1, arg2, arg3,
    kwarg1=value1, kwarg2=value2
)

# ✅ 正确 - 使用括号
message = (
    "This is a very long message that "
    "spans multiple lines"
)
```

### 空行
- **2 行**: 类之间、顶级函数之间
- **1 行**: 方法之间、函数内逻辑分组

```python
# ✅ 正确
class FirstClass:
    pass


class SecondClass:
    
    def first_method(self):
        pass
    
    def second_method(self):
        pass
```

### 空格
```python
# ✅ 正确
x = 1
y = x + 2
result = function(arg1, arg2)
my_list = [1, 2, 3]

# ❌ 错误
x=1
y = x+2
result = function( arg1,arg2 )
my_list = [1,2,3]
```

## 📦 导入规范

### 导入顺序
1. 标准库
2. 相关第三方库
3. 本地应用/库

**每组之间空一行**

```python
# ✅ 正确
import os
import sys

import requests
from django.conf import settings

from myapp.models import User
from myapp.utils import helper

# ❌ 错误 - 顺序混乱
from myapp.models import User
import requests
import os
```

### 导入方式
```python
# ✅ 推荐
import os
import sys

# ✅ 可接受
from os import path
from django.conf import settings

# ❌ 避免
from os import *  # 污染命名空间
```

## 💬 注释规范

### 行内注释
- 与代码至少 2 个空格
- 以 `#` 开头，后跟 1 个空格

```python
# ✅ 正确
x = x + 1  # 补偿边界

# ❌ 错误
x = x + 1 #补偿边界  # 缺少空格
```

### 文档字符串 (Docstring)
- 使用三重双引号 `"""`
- 遵循 PEP 257

```python
# ✅ 正确 - 单行文档
def simple_function():
    """这是一个简单的函数。"""
    pass

# ✅ 正确 - 多行文档
def complex_function(arg1, arg2):
    """
    这是一个复杂的函数。
    
    Args:
        arg1 (int): 第一个参数
        arg2 (str): 第二个参数
    
    Returns:
        bool: 操作是否成功
    
    Raises:
        ValueError: 如果参数无效
    """
    pass
```

## 🔧 编程实践

### 字符串
```python
# ✅ 推荐 - f-string (Python 3.6+)
name = "Alice"
message = f"Hello, {name}!"

# ✅ 可接受 - format
message = "Hello, {}!".format(name)

# ❌ 避免 - 字符串拼接
message = "Hello, " + name + "!"  # 性能较差
```

### 列表推导式
```python
# ✅ 推荐
squares = [x**2 for x in range(10)]

# ❌ 避免 - 过于复杂
result = [x**2 for x in range(10) if x % 2 == 0 if x > 5]  # 太长，难读
```

### 默认参数
```python
# ✅ 正确 - 不可变默认参数
def good_function(x, items=None):
    if items is None:
        items = []
    items.append(x)
    return items

# ❌ 危险 - 可变默认参数
def bad_function(x, items=[]):  # 共享同一个列表
    items.append(x)
    return items
```

### 比较
```python
# ✅ 正确 - 单例比较用 is
if x is None:
    pass

if x is True:
    pass

# ✅ 正确 - 布尔值比较
if my_list:  # 检查非空
    pass

if not my_list:  # 检查空
    pass

# ❌ 错误
if x == None:  # 应该用 is
    pass

if len(my_list) > 0:  # 冗余
    pass
```

### 异常处理
```python
# ✅ 正确 - 具体异常
try:
    value = int(user_input)
except ValueError as e:
    print(f"Invalid input: {e}")

# ❌ 错误 - 捕获所有异常
try:
    value = int(user_input)
except:  # 太宽泛
    pass
```

## 🛠️ 工具链

### 代码检查
```bash
# pylint - 全面的代码检查
pip install pylint
pylint myfile.py

# flake8 - PEP 8 风格检查
pip install flake8
flake8 myfile.py

# mypy - 类型检查
pip install mypy
mypy myfile.py
```

### 自动格式化
```bash
# black - 无妥协的代码格式化
pip install black
black myfile.py

# autopep8 - 自动修复 PEP 8 问题
pip install autopep8
autopep8 --in-place myfile.py
```

### 配置文件
```ini
# .flake8
[flake8]
max-line-length = 88
exclude = .git,__pycache__,venv
ignore = E203,W503

# pyproject.toml (black)
[tool.black]
line-length = 88
target-version = ['py38']
```

- [ ] 类名使用 PascalCase

- [ ] 常量使用 UPPER_SNAKE_CASE
- [ ] 导入按标准库、第三方、本地顺序
- [ ] 避免 `from module import *`
- [ ] 所有公共函数有文档字符串

- [ ] 具体异常而非 `except:`
