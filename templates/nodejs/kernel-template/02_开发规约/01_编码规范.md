# JavaScript/TypeScript 编码规范

> 基于 Airbnb JavaScript Style Guide

---

## 🎯 核心原则

1. **清晰胜于简洁**: 可读性优先
2. **一致性**: 保持代码风格统一
3. **现代化**: 使用 ES6+ 特性
4. **类型安全**: 优先使用 TypeScript

---

## 📝 命名规范

### 变量和函数
- **camelCase**: `myVariable`, `myFunction()`
- **布尔值**: 以 `is/has/should` 开头

```javascript
// ✅ 正确
const userName = 'John';
const isActive = true;
const hasPermission = false;

function getUserData() {}

// ❌ 错误
const user_name = 'John';  // 应该用 camelCase
const active = true;       // 布尔值应该以 is 开头
function get_user_data() {} // 应该用 camelCase
```

### 类和构造函数
- **PascalCase**: `class MyClass`

```javascript
// ✅ 正确
class UserProfile {
  constructor(name) {
    this.name = name;
  }
}

// ❌ 错误
class userProfile {}  // 应该用 PascalCase
```

### 常量
- **UPPER_SNAKE_CASE**: `const MAX_SIZE = 100`

```javascript
// ✅ 正确
const MAX_RETRY_COUNT = 3;
const API_BASE_URL = 'https://api.example.com';

// ❌ 错误
const maxRetryCount = 3;  // 常量应该用 UPPER_SNAKE_CASE
```

### 私有属性
- **下划线前缀**: `_privateMethod()`

```javascript
class MyClass {
  constructor() {
    this._privateProperty = 'secret';
  }
  
  _privateMethod() {
    // 私有方法
  }
}
```

## 📐 代码格式

### 缩进
- **2 个空格**（不使用 Tab）

```javascript
// ✅ 正确
function myFunction() {
  if (condition) {
    doSomething();
  }
}

// ❌ 错误 (4个空格)
function myFunction() {
    if (condition) {
        doSomething();
    }
}
```

### 分号
- **强制使用分号**

```javascript
// ✅ 正确
const x = 1;
const y = 2;

// ❌ 错误
const x = 1
const y = 2
```

### 引号
- **优先单引号** `'string'`
- **模板字符串使用反引号** `` `template` ``

```javascript
// ✅ 正确
const name = 'John';
const message = `Hello, ${name}!`;

// ❌ 错误
const name = "John";  // 应该用单引号
const message = 'Hello, ' + name + '!';  // 应该用模板字符串
```

### 行长度
- **最大 100 字符**

### 对象和数组
```javascript
// ✅ 正确 - 短对象单行
const obj = { a: 1, b: 2 };

// ✅ 正确 - 长对象多行
const obj = {
  firstName: 'John',
  lastName: 'Doe',
  age: 30,
};

// ✅ 正确 - 尾随逗号
const arr = [
  'apple',
  'banana',
  'orange',
];
```

## 🔧 ES6+ 特性

### 变量声明
```javascript
// ✅ 推荐 - 使用 const
const MAX_SIZE = 100;
const user = { name: 'John' };

// ✅ 可接受 - 使用 let
let counter = 0;
counter++;

// ❌ 避免 - 使用 var
var name = 'John';  // 作用域混乱
```

### 箭头函数
```javascript
// ✅ 推荐 - 箭头函数
const double = (x) => x * 2;
const sum = (a, b) => a + b;

// ✅ 正确 - 多行箭头函数
const process = (data) => {
  const result = data.map(x => x * 2);
  return result.filter(x => x > 10);
};

// ❌ 避免 - function 表达式
const double = function(x) {  // 应该用箭头函数
  return x * 2;
};
```

### 解构赋值
```javascript
// ✅ 推荐 - 对象解构
const { firstName, lastName } = user;
const { name, age = 18 } = user;  // 默认值

// ✅ 推荐 - 数组解构
const [first, second] = arr;
const [head, ...tail] = arr;  // 剩余元素

// ✅ 推荐 - 函数参数解构
function greet({ name, age }) {
  return `Hello ${name}, ${age} years old`;
}
```

### 模板字符串
```javascript
// ✅ 推荐
const message = `Hello, ${name}!`;
const multiLine = `
  Line 1
  Line 2
  Line 3
`;

// ❌ 避免
const message = 'Hello, ' + name + '!';
```

### 展开运算符
```javascript
// ✅ 推荐 - 数组拷贝
const newArr = [...oldArr];

// ✅ 推荐 - 对象拷贝
const newObj = { ...oldObj, newProp: 'value' };

// ✅ 推荐 - 函数参数
function sum(...numbers) {
  return numbers.reduce((a, b) => a + b, 0);
}
```

### Promise 和 async/await
```javascript
// ✅ 推荐 - async/await
async function fetchUser(id) {
  try {
    const response = await fetch(`/api/users/${id}`);
    const user = await response.json();
    return user;
  } catch (error) {
    console.error('Failed to fetch user:', error);
    throw error;
  }
}

// ❌ 避免 - Promise 链（可读性差）
function fetchUser(id) {
  return fetch(`/api/users/${id}`)
    .then(response => response.json())
    .then(user => user)
    .catch(error => {
      console.error(error);
      throw error;
    });
}
```

## 📦 模块系统

### ES6 Modules
```javascript
// ✅ 推荐 - 具名导出
export const add = (a, b) => a + b;
export const subtract = (a, b) => a - b;

// ✅ 推荐 - 默认导出
export default class User {}

// ✅ 推荐 - 导入
import User from './User';
import { add, subtract } from './math';
import * as math from './math';

// ❌ 避免 - CommonJS
const User = require('./User');  // 应该用 ES6 import
module.exports = User;            // 应该用 ES6 export
```

## 🎨 函数规范

### 函数长度
- **最大 50 行**（复杂函数应拆分）

### 参数数量
- **最多 3 个参数**（超过使用对象）

```javascript
// ✅ 正确 - 参数对象
function createUser({ name, email, age, role }) {
  // ...
}

// ❌ 错误 - 参数过多
function createUser(name, email, age, role, department, manager) {
  // 难以维护
}
```

### 纯函数
```javascript
// ✅ 推荐 - 纯函数
function add(a, b) {
  return a + b;  // 无副作用
}

// ❌ 避免 - 有副作用
let total = 0;
function add(a, b) {
  total = a + b;  // 修改外部变量
  return total;
}
```

## 🔍 条件和循环

### 条件判断
```javascript
// ✅ 推荐 - 简洁条件
if (isActive) {
  // ...
}

if (!isDeleted) {
  // ...
}

// ❌ 避免
if (isActive === true) {  // 冗余
  // ...
}

// ✅ 推荐 - 三元运算符（简单情况）
const status = isActive ? 'active' : 'inactive';

// ❌ 避免 - 嵌套三元（难读）
const result = a ? b : c ? d : e ? f : g;
```

### 循环
```javascript
// ✅ 推荐 - 数组方法
const doubled = numbers.map(n => n * 2);
const evens = numbers.filter(n => n % 2 === 0);
const sum = numbers.reduce((a, b) => a + b, 0);

// ✅ 可接受 - for...of
for (const item of items) {
  console.log(item);
}

// ❌ 避免 - 传统 for 循环（除非性能关键）
for (let i = 0; i < items.length; i++) {
  console.log(items[i]);
}
```

## 🛡️ 类型安全 (TypeScript)

### 基础类型
```typescript
// ✅ 正确
const name: string = 'John';
const age: number = 30;
const isActive: boolean = true;
const items: string[] = ['a', 'b', 'c'];

// ✅ 正确 - 对象类型
interface User {
  id: number;
  name: string;
  email: string;
  age?: number;  // 可选
}

const user: User = {
  id: 1,
  name: 'John',
  email: 'john@example.com'
};
```

### 函数类型
```typescript
// ✅ 正确
function add(a: number, b: number): number {
  return a + b;
}

// ✅ 正确 - 箭头函数
const multiply = (a: number, b: number): number => a * b;

// ✅ 正确 - 异步函数
async function fetchUser(id: number): Promise<User> {
  const response = await fetch(`/api/users/${id}`);
  return response.json();
}
```

### 泛型
```typescript
// ✅ 正确
function identity<T>(arg: T): T {
  return arg;
}

interface ApiResponse<T> {
  data: T;
  status: number;
  message: string;
}

const response: ApiResponse<User> = {
  data: user,
  status: 200,
  message: 'Success'
};
```

## 🧪 测试规范

### Jest 测试
```javascript
// user.test.js
import { createUser, getUser } from './user';

describe('User Service', () => {
  describe('createUser', () => {
    it('should create a new user', async () => {
      const userData = {
        name: 'John',
        email: 'john@example.com'
      };
      
      const user = await createUser(userData);
      
      expect(user).toHaveProperty('id');
      expect(user.name).toBe('John');
    });
    
    it('should throw error for duplicate email', async () => {
      const userData = { name: 'John', email: 'test@example.com' };
      
      await createUser(userData);
      
      await expect(createUser(userData)).rejects.toThrow('Email exists');
    });
  });
});
```

## 🛠️ 工具链

### ESLint 配置
```javascript
// .eslintrc.js
module.exports = {
  extends: [
    'airbnb-base',  // Airbnb 规范
    'plugin:@typescript-eslint/recommended',  // TypeScript
    'prettier'  // Prettier 集成
  ],
  parser: '@typescript-eslint/parser',
  plugins: ['@typescript-eslint'],
  rules: {
    'no-console': 'warn',
    'no-unused-vars': 'error',
    'prefer-const': 'error',
    'arrow-body-style': ['error', 'as-needed'],
  }
};
```

### Prettier 配置
```javascript
// .prettierrc.js
module.exports = {
  singleQuote: true,
  trailingComma: 'all',
  printWidth: 100,
  tabWidth: 2,
  semi: true,
  arrowParens: 'always',
};
```

### 安装和使用
```bash
# 安装 ESLint + Prettier
npm install --save-dev eslint prettier
npm install --save-dev eslint-config-airbnb-base
npm install --save-dev eslint-config-prettier
npm install --save-dev @typescript-eslint/eslint-plugin
npm install --save-dev @typescript-eslint/parser

# 检查代码
npm run lint

# 自动修复
npm run lint:fix

# 格式化代码
npm run format

# package.json scripts
{
  "scripts": {
    "lint": "eslint . --ext .js,.ts",
    "lint:fix": "eslint . --ext .js,.ts --fix",
    "format": "prettier --write \"**/*.{js,ts,json,md}\""
  }
}
```
