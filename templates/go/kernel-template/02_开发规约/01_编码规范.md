# Go 编码规范

> 基于 Effective Go 官方规范

---

## 🎯 核心原则

1. **简洁明了**: 代码应该清晰易读
2. **显式优于隐式**: 明确的代码优于"聪明"的代码
3. **组合优于继承**: 使用接口和组合
4. **并发思维**: 充分利用 goroutine 和 channel

---

## 📝 命名规范

### 包名
- **小写单词**: `package http`, `package json`
- **不使用下划线或驼峰**: 使用短小有意义的名称

```go
// ✅ 正确
package user
package httputil

// ❌ 错误
package user_service  // 不用下划线
package UserService   // 不用大写
package userMgr       // 避免缩写
```

### 变量和函数
- **驼峰命名**: `camelCase` (私有) 或 `PascalCase` (公开)
- **首字母大小写决定可见性**

```go
// ✅ 正确 - 导出（公开）
type User struct {
    Name  string  // 公开字段
    Email string
}

func GetUser(id int) (*User, error) {  // 公开函数
    // ...
}

// ✅ 正确 - 未导出（私有）
type userCache struct {
    data map[int]*User  // 私有字段
}

func validateEmail(email string) bool {  // 私有函数
    // ...
}

// ❌ 错误
func get_user(id int) {}  // 应该用驼峰
```

### 常量
- **驼峰命名**（不用 UPPER_SNAKE_CASE）

```go
// ✅ 正确
const MaxSize = 100
const defaultTimeout = 30

// ❌ 错误
const MAX_SIZE = 100  // Go 不推荐全大写
```

### 接口
- **单方法接口**: 以 `er` 结尾

```go
// ✅ 正确
type Reader interface {
    Read(p []byte) (n int, err error)
}

type Writer interface {
    Write(p []byte) (n int, err error)
}

type Stringer interface {
    String() string
}

// ✅ 正确 - 多方法接口
type UserService interface {
    GetUser(id int) (*User, error)
    CreateUser(user *User) error
}
```

## 📐 代码格式

### 自动格式化
- **使用 gofmt**（官方工具，无争议）

```bash
# 格式化单个文件
gofmt -w myfile.go

# 格式化整个项目
gofmt -w .

# 检查格式（不修改）
gofmt -l .
```

### 缩进
- **Tab 缩进**（gofmt 强制）

### 行长度
- **无硬性限制**（推荐 < 100 字符）

### 括号
```go
// ✅ 正确 - 左括号不换行
func main() {
    if condition {
        doSomething()
    }
}

// ❌ 错误 - 左括号换行
func main() 
{  // gofmt 会自动修正
    // ...
}
```

## 🔧 语言特性

### 错误处理
- **显式检查错误**（不使用异常）

```go
// ✅ 正确
func GetUser(id int) (*User, error) {
    user, err := db.Query("SELECT * FROM users WHERE id = ?", id)
    if err != nil {
        return nil, fmt.Errorf("failed to get user: %w", err)
    }
    return user, nil
}

// ✅ 正确 - 调用方处理
user, err := GetUser(123)
if err != nil {
    log.Printf("Error: %v", err)
    return err
}

// ❌ 错误 - 忽略错误
user, _ := GetUser(123)  // 不应忽略错误
```

### defer
```go
// ✅ 推荐 - 资源清理
func ReadFile(path string) ([]byte, error) {
    file, err := os.Open(path)
    if err != nil {
        return nil, err
    }
    defer file.Close()  // 函数返回时自动关闭
    
    return io.ReadAll(file)
}

// ✅ 正确 - defer 顺序（LIFO）
func example() {
    defer fmt.Println("3")
    defer fmt.Println("2")
    defer fmt.Println("1")
    // 输出顺序: 1, 2, 3
}
```

### goroutine 和 channel
```go
// ✅ 推荐 - 并发处理
func ProcessData(items []string) []Result {
    results := make(chan Result, len(items))
    
    for _, item := range items {
        go func(item string) {
            result := process(item)
            results <- result
        }(item)  // 传递参数避免闭包问题
    }
    
    // 收集结果
    var output []Result
    for i := 0; i < len(items); i++ {
        output = append(output, <-results)
    }
    return output
}

// ✅ 推荐 - 使用 sync.WaitGroup
func ProcessWithWaitGroup(items []string) {
    var wg sync.WaitGroup
    
    for _, item := range items {
        wg.Add(1)
        go func(item string) {
            defer wg.Done()
            process(item)
        }(item)
    }
    
    wg.Wait()  // 等待所有 goroutine 完成
}
```

### 接口和组合
```go
// ✅ 推荐 - 小接口
type Reader interface {
    Read(p []byte) (n int, err error)
}

type Closer interface {
    Close() error
}

// ✅ 推荐 - 接口组合
type ReadCloser interface {
    Reader
    Closer
}

// ✅ 推荐 - 结构体组合
type Logger struct {
    writer io.Writer
}

type Service struct {
    Logger  // 嵌入，继承 Logger 的方法
    db *sql.DB
}
```

## 📦 包管理

### 项目结构
```
myproject/
├── go.mod              # 模块定义
├── go.sum              # 依赖校验
├── main.go             # 主入口
│
├── cmd/                # 可执行文件
│   └── server/
│       └── main.go
│
├── internal/           # 私有代码（不可被外部导入）
│   ├── user/
│   │   ├── user.go
│   │   └── user_test.go
│   └── db/
│       └── db.go
│
├── pkg/                # 可被外部导入的库
│   └── util/
│       └── util.go
│
└── api/                # API 定义
    └── proto/
```

```bash

# 添加依赖
go get github.com/gin-gonic/gin

# 整理依赖
go mod tidy

# 查看依赖
go list -m all
```

## 🧪 测试规范

### 测试文件
- **文件名**: `xxx_test.go`
- **函数名**: `TestXxx`

```go
// user_test.go
package user

import "testing"

func TestGetUser(t *testing.T) {
    user, err := GetUser(123)
    if err != nil {
        t.Fatalf("GetUser failed: %v", err)
    }
    
    if user.Name != "John" {
        t.Errorf("expected name John, got %s", user.Name)
    }
}

// 表格驱动测试
func TestAdd(t *testing.T) {
    tests := []struct {
        name     string
        a, b     int
        expected int
    }{
        {"positive", 1, 2, 3},
        {"negative", -1, -2, -3},
        {"zero", 0, 0, 0},
    }
    
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            result := Add(tt.a, tt.b)
            if result != tt.expected {
                t.Errorf("Add(%d, %d) = %d; want %d", 
                    tt.a, tt.b, result, tt.expected)
            }
        })
    }
}
```

### 基准测试
```go
func BenchmarkAdd(b *testing.B) {
    for i := 0; i < b.N; i++ {
        Add(1, 2)
    }
}

// 运行基准测试
// go test -bench=.
```

## 🛡️ 最佳实践

### 变量声明
```go
// ✅ 推荐 - 短变量声明
name := "John"
count := 10

// ✅ 推荐 - 零值初始化
var users []User  // nil slice
var count int     // 0

// ✅ 推荐 - 显式类型
var timeout time.Duration = 30 * time.Second
```

### 切片和映射
```go
// ✅ 推荐 - 使用 make 预分配
users := make([]User, 0, 100)  // 容量 100
cache := make(map[int]string, 50)

// ❌ 避免 - 直接声明（nil）
var users []User
users[0] = User{}  // panic: index out of range

// ✅ 正确 - 检查 map key
value, ok := cache[key]
if !ok {
    // key 不存在
}
```

### 上下文传递
```go
// ✅ 推荐 - 使用 context.Context
func GetUser(ctx context.Context, id int) (*User, error) {
    // 检查取消
    select {
    case <-ctx.Done():
        return nil, ctx.Err()
    default:
    }
    
    // 执行查询
    return db.QueryContext(ctx, "SELECT * FROM users WHERE id = ?", id)
}

// 调用时传递 context
ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
defer cancel()

user, err := GetUser(ctx, 123)
```
