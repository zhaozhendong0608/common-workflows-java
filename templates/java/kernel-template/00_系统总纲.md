## 开发原则

### P0 原则（强制）
1. **安全第一**: 所有 API 必须认证授权
2. **测试先行**: 核心功能必须有单元测试
3. **代码审查**: 所有 PR 必须经过 Review

### P1 原则（建议）
1. **简单至上**: 优先使用简单方案
2. **文档同步**: 代码变更同步更新文档
3. **性能优先**: API 响应时间 < 200ms
