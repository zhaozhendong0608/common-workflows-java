## 最佳实践

### ✅ 推荐做法

1. **渐进式填充**: 不要一次性填完所有内容
2. **实时更新**: 开发过程中随时更新
3. **团队共识**: 重要决策团队讨论后记录
4. **定期复盘**: 每月回顾 ADR 和 FAQ

### ❌ 避免做法

1. **过度详细**: 不要写成小说
2. **过时不更新**: 内容要保持时效性
3. **只写不用**: 写了要真正参考
4. **格式混乱**: 保持统一格式
