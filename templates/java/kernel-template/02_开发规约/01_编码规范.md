# 01_编码规范 (Coding Standards)

> **说明**: Java 项目通用编码规范，可直接使用

## 命名规范
### 类命名
- **规则**: PascalCase（大驼峰）
- **示例**:
 ```java
 public class UserService { } // ✅ 正确
 public class userService { } // ❌ 错误
 public class User_Service { } // ❌ 错误
 ```

### 接口命名
- **规则**: PascalCase，推荐以 I 开头或不加前缀
- **示例**:
 ```java
 public interface IUserService { } // ✅ 推荐
 public interface UserService { } // ✅ 可接受
 ```

### 方法命名
- **规则**: camelCase（小驼峰）
- **示例**:
 ```java
 public void getUserById() { } // ✅ 正确
 public void GetUserById() { } // ❌ 错误
 public void get_user_by_id() { } // ❌ 错误
 ```

### 变量命名
- **规则**: camelCase
- **示例**:
 ```java
 String userName = "admin"; // ✅ 正确
 String UserName = "admin"; // ❌ 错误
 String user_name = "admin"; // ❌ 错误
 ```

### 常量命名
- **规则**: UPPER_SNAKE_CASE
- **示例**:
 ```java
 public static final int MAX_SIZE = 100; // ✅ 正确
 public static final String DEFAULT_USERNAME = "admin"; // ✅ 正确
 public static final int maxSize = 100; // ❌ 错误
 ```

### 包命名
- **规则**: 全小写，点分隔
- **示例**:
 ```java
 package com.company.project.service; // ✅ 正确
 package com.company.Project.Service; // ❌ 错误
 ```

## 代码格式
### 缩进
- **规则**: 使用 4 个空格，禁止使用 Tab
- **示例**:
 ```java
 public class User {
 private String name; // 4 空格缩进

 public String getName() {
 return name; // 8 空格缩进
 }
 }
 ```

### 行宽
- **规则**: 单行不超过 120 字符
- **超长处理**: 适当换行
 ```java
 // ✅ 正确
 public void doSomething(String param1, String param2,
 String param3, String param4) {
 // ...
 }

 // ❌ 错误（超过 120 字符）
 public void doSomething(String param1, String param2, String param3, String param4, String param5, String param6) { }
 ```

### 空格
- **规则**:
- 关键字后加空格：`if (`, `for (`, `while (`
- 运算符两边加空格：`a + b`, `x == y`
- 逗号后加空格：`foo(a, b, c)`

### 空行
- **规则**:
- 类成员之间 1 行
- 方法之间 1 行
- 逻辑块之间 1 行

## 注释规范
### 类注释
```java
/**
 * 用户服务类
 *

 * @since 1.0
 */

}
```

```java
 * @throws UserNotFoundException 用户不存在时抛出
 */

// ...
}
```

### 单行注释
```java

}
```


## 编码实践

### 1. 使用 final 关键字
```java
// ✅ 推荐
public class UserService {
 private final UserMapper userMapper; // 不可变字段
 public void process(final String param) { // 不可变参数
 // ...
 }
}
```

### 2. 避免魔法数字
```java
// ❌ 错误
if (status == 1) { }

// ✅ 正确
private static final int STATUS_ACTIVE = 1;
if (status == STATUS_ACTIVE) { }
```

### 3. 使用枚举代替常量
```java
// ✅ 推荐
public enum UserStatus {
 ACTIVE(1, "激活"),
 DISABLED(0, "禁用");

 private final int code;
 private final String desc;

 // ...
}
```

### 4. 合理使用 Optional
```java
// ✅ 推荐
public Optional<User> getUserById(Long userId) {
 return Optional.ofNullable(userMapper.selectById(userId));
}

// 使用
getUserById(1L).ifPresent(user -> {
// 处理用户
});
```

### 5. 异常处理
```java
// ✅ 正确
try {
 // 业务逻辑
} catch (SpecificException e) {
 log.error("业务异常: {}", e.getMessage(), e);
 throw new BusinessException("操作失败", e);
}

// ❌ 错误
try {
 // 业务逻辑
} catch (Exception e) {
 e.printStackTrace(); // 不要使用 printStackTrace
}
```

### 6. 日志规范
```java
// ✅ 推荐
log.info("用户登录成功, userId={}", userId);
log.error("用户登录失败, username={}, error={}", username, e.getMessage(), e);

// ❌ 错误
log.info("用户登录成功, userId=" + userId); // 不要用字符串拼接
System.out.println("Debug info"); // 不要用 println
```

## 资源管理

### 使用 try-with-resources
```java
// ✅ 推荐
try (InputStream is = new FileInputStream("file.txt");
 BufferedReader br = new BufferedReader(new InputStreamReader(is))) {
// 读取文件
}

// ❌ 错误
InputStream is = null;
try {
 is = new FileInputStream("file.txt");
 // ...
} finally {
 if (is != null) {
 is.close();
 }
}
```

## 集合操作

### 使用 Stream API
```java
// ✅ 推荐
List<String> names = users.stream()
 .map(User::getName)
 .filter(name -> name.startsWith("A"))
 .collect(Collectors.toList());

// 链式调用适当换行
List<UserDTO> dtos = users.stream()
 .filter(user -> user.getStatus() == 1)
 .map(this::convertToDTO)
 .sorted(Comparator.comparing(UserDTO::getCreateTime).reversed())
 .collect(Collectors.toList());
```

## 禁止事项

### ❌ 禁止
1. 使用 `System.out.println()` 打印日志
2. 捕获异常后不处理（空 catch 块）
3. 在循环中拼接字符串（使用 StringBuilder）
4. 在代码中硬编码敏感信息（密码、密钥）
5. 使用过时的 API（@Deprecated）
