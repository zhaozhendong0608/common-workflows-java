# 00_系统总纲 (Kernel)

**项目名称**: 智明工业数据智能分析平台（示例）
**项目代号**: etl-station
**核心使命**: 为工业企业提供数据采集、分析、可视化的一体化解决方案
**技术负责人**: 张三

---

## 技术栈

### 后端
- **框架**: Spring Boot 2.7.5
- **数据库**: MySQL 8.0 + Redis 7.0 + 极生TDB（时序数据库）
- **ORM**: MyBatis Plus 3.5.3
- **缓存**: Redis + Caffeine（本地缓存）

### 前端
- **框架**: Vue 3.2
- **UI库**: Element Plus
- **构建工具**: Vite 4.0

### 其他
- **消息队列**: RabbitMQ 3.11
- **注册中心**: Nacos 2.2
- **API 网关**: Spring Cloud Gateway

---

## 开发原则

### P0 原则（强制）
1. **安全第一**: 所有 API 必须认证授权
2. **测试先行**: 核心功能必须有单元测试
3. **代码审查**: 所有 PR 必须经过 Review

### P1 原则（建议）
1. **简单至上**: 优先使用简单方案
2. **文档同步**: 代码变更同步更新文档
3. **性能优先**: API 响应时间 < 200ms

---

## 架构模式

### 整体架构
**前后端分离 + 微服务架构**

```
前端 (Vue 3) 
    ↓
API 网关 (Spring Gateway)
    ↓
微服务层 (Spring Boot)
  ├─ 用户服务
  ├─ 设备服务
  └─ 数据服务
    ↓
数据层 (MySQL + Redis + TDB)
```

### 目录结构
```
src/main/java/com/example/etl/
├── controller/     # 控制层
├── service/        # 业务层
├── mapper/         # 数据访问层
├── entity/         # 实体类
├── dto/            # 数据传输对象
├── vo/             # 视图对象
└── common/         # 公共组件
```
