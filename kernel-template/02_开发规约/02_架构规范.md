# 02_架构规范 (Architecture Standards)

> **说明**: Java 项目通用架构规范，基于 MVC 三层架构

## 分层架构

### 标准三层架构

```
┌─────────────────────────────────┐
│ Controller Layer (控制器层) │ ← 接收请求，参数校验
└─────────────────────────────────┘
↓
┌─────────────────────────────────┐
│ Service Layer (业务逻辑层) │ ← 业务逻辑，事务控制
└─────────────────────────────────┘
↓
┌─────────────────────────────────┐
│ Repository Layer (数据访问层) │ ← 数据访问，SQL 执行
└─────────────────────────────────┘
↓
┌─────────────────────────────────┐
│ Database (数据库) │
└─────────────────────────────────┘
```

### 分层职责

| 层级 | 职责 | 禁止 |
|------|------|------|
| **Controller** | 参数校验、调用 Service、返回结果 | ❌ 业务逻辑<br>❌ 直接调用 Repository |
| **Service** | 业务逻辑、事务控制、调用 Repository | ❌ 直接操作数据库连接 |
| **Repository** | SQL 执行、数据映射 | ❌ 业务逻辑 |

## Controller 规范

### 标准写法

```java
@RestController
@RequestMapping("/api/user")
@Slf4j
public class UserController {

 private final IUserService userService;

 public UserController(IUserService userService) {
 this.userService = userService;
 }

 /**
 * 创建用户
 */
 @PostMapping
 public Result<Long> create(@Valid @RequestBody UserCreateDTO dto) {
 Long userId = userService.create(dto);
 return Result.success(userId);
 }

 /**
 * 查询用户
 */
 @GetMapping("/{id}")
 public Result<UserVO> getById(@PathVariable Long id) {
 UserVO user = userService.getById(id);
 return Result.success(user);
 }

 /**
 * 更新用户
 */
 @PutMapping("/{id}")
 public Result<Void> update(@PathVariable Long id,
 @Valid @RequestBody UserUpdateDTO dto) {
 userService.update(id, dto);
 return Result.success();
 }

 /**
 * 删除用户
 */
 @DeleteMapping("/{id}")
 public Result<Void> delete(@PathVariable Long id) {
 userService.delete(id);
 return Result.success();
 }
}
```

### Controller 约束

✅ **应该做**:
- 使用 `@RestController` 或 `@Controller`
- 参数校验使用 `@Valid`
- 统一返回 `Result<T>` 包装类
- 使用依赖注入（构造器注入优于字段注入）

❌ **不应该做**:
- 不在 Controller 中写业务逻辑
- 不直接调用 Mapper/Repository
- 不在 Controller 中操作事务

## Service 规范

### 接口定义

```java
public interface IUserService {

 /**
 * 创建用户
 */
 Long create(UserCreateDTO dto);

 /**
 * 查询用户
 */
 UserVO getById(Long id);

 /**
 * 更新用户
 */
 void update(Long id, UserUpdateDTO dto);

 /**
 * 删除用户
 */
 void delete(Long id);
}
```

### 实现类

```java
@Service
@Slf4j
public class UserServiceImpl implements IUserService {

 private final UserMapper userMapper;

 public UserServiceImpl(UserMapper userMapper) {
 this.userMapper = userMapper;
 }

 @Override
 @Transactional(rollbackFor = Exception.class)
 public Long create(UserCreateDTO dto) {
 // 1. 参数校验
 validateUser(dto);

 // 2. 业务逻辑
 User user = convertToEntity(dto);
 user.setCreateTime(LocalDateTime.now());

 // 3. 数据持久化
 userMapper.insert(user);

 return user.getId();
 }

 @Override
 public UserVO getById(Long id) {
 User user = userMapper.selectById(id);
 if (user == null) {
 throw new BusinessException("用户不存在");
 }
 return convertToVO(user);
 }

 @Override
 @Transactional(rollbackFor = Exception.class)
 public void delete(Long id) {
 // 业务校验
 checkCanDelete(id);

 // 执行删除
 userMapper.deleteById(id);
 }

 private void validateUser(UserCreateDTO dto) {
 // 业务校验逻辑
 }

 private void checkCanDelete(Long id) {
 // 删除前校验
 }
}
```

### Service 约束

✅ **应该做**:
- 使用 `@Service` 注解
- 接口与实现分离
- 事务方法使用 `@Transactional`
- 明确的异常处理

❌ **不应该做**:
- 不在 Service 中直接操作 JDBC 连接
- 不在 Service 中处理 HTTP 请求/响应

## Repository 规范

### Mapper 接口

```java
@Mapper
public interface UserMapper extends BaseMapper<User> {

 /**
 * 根据用户名查询
 */
 @Select("SELECT * FROM sys_user WHERE username = #{username}")
 User selectByUsername(@Param("username") String username);

 /**
 * 统计用户数
 */
 @Select("SELECT COUNT(*) FROM sys_user WHERE dept_id = #{deptId}")
 int countByDeptId(@Param("deptId") Long deptId);
}
```

### Repository 约束

✅ **应该做**:
- 使用 `@Mapper` 注解
- 使用参数化查询（`#{param}`）
- 复杂查询写在 XML 中

❌ **不应该做**:
- 禁止 SQL 拼接（防止注入）
- 不在 Mapper 中写业务逻辑

## 依赖注入规范

### 推荐：构造器注入

```java
// ✅ 推荐
@Service
public class UserService {
 private final UserMapper userMapper;
 private final DeptMapper deptMapper;

 public UserService(UserMapper userMapper, DeptMapper deptMapper) {
 this.userMapper = userMapper;
 this.deptMapper = deptMapper;
 }
}
```

### 不推荐：字段注入

```java
// ⚠️ 不推荐
@Service
public class UserService {
 @Autowired
 private UserMapper userMapper;
}
```

**理由**:
- 构造器注入强制依赖明确
- 支持 final 字段
- 便于单元测试

## 事务管理

### 事务注解

```java
@Transactional(rollbackFor = Exception.class)
public void updateUser(Long id, UserUpdateDTO dto) {
 // 所有异常都回滚
}
```

### 事务传播

```java
// 必须在事务中运行
@Transactional(propagation = Propagation.REQUIRED)
public void required() { }

// 必须在新事务中运行
@Transactional(propagation = Propagation.REQUIRES_NEW)
public void requiresNew() { }
```

### 事务约束

✅ **应该做**:
- 明确 `rollbackFor = Exception.class`
- 事务方法放在 Service 层
- 事务范围尽可能小

❌ **不应该做**:
- 不在 Controller 中使用 `@Transactional`
- 不在事务中调用外部 HTTP 接口
- 不在事务中执行长时间操作

## 异常处理

### 异常层次

```
Exception
 └── RuntimeException
 ├── BusinessException # 业务异常
 ├── ValidationException # 参数校验异常
 └── SystemException # 系统异常
```

### 统一异常处理

```java
@RestControllerAdvice
@Slf4j
public class GlobalExceptionHandler {

 /**
 * 业务异常
 */
 @ExceptionHandler(BusinessException.class)
 public Result<Void> handleBusinessException(BusinessException e) {
 log.warn("业务异常: {}", e.getMessage());
 return Result.fail(e.getCode(), e.getMessage());
 }

 /**
 * 参数校验异常
 */
 @ExceptionHandler(MethodArgumentNotValidException.class)
 public Result<Void> handleValidationException(MethodArgumentNotValidException e) {
 String message = e.getBindingResult().getFieldError().getDefaultMessage();
 return Result.fail(400, message);
 }

 /**
 * 系统异常
 */
 @ExceptionHandler(Exception.class)
 public Result<Void> handleException(Exception e) {
 log.error("系统异常", e);
 return Result.fail(500, "系统异常，请联系管理员");
 }
}
```

## DTO/VO/Entity 规范

### 数据传输对象

```
Entity ←→ DTO ←→ Controller ←→ VO ←→ 前端
(数据库) (内部) (接口) (展示)
```

| 类型 | 用途 | 位置 |
|------|------|------|
| **Entity** | 数据库实体 | repository/entity/ |
| **DTO** | 接收前端数据 | api/dto/ |
| **VO** | 返回给前端 | api/vo/ |

### 示例

```java
// Entity
@Data
@TableName("sys_user")
public class User {
 @TableId(type = IdType.ASSIGN_ID)
 private Long id;
 private String username;
 private String password; // 密码字段
 private LocalDateTime createTime;
}

// DTO（接收）
@Data
public class UserCreateDTO {
 @NotBlank(message = "用户名不能为空")
 private String username;

 @NotBlank(message = "密码不能为空")
 private String password;
}

// VO（返回）
@Data
public class UserVO {
 private Long id;
 private String username;
 // 不返回密码字段
 private String createTime;
}
```

## 跨层调用规范

### ✅ 允许的调用

```
Controller → Service → Repository
Controller → Service1 → Service2
```

### ❌ 禁止的调用

```
Controller → Repository ❌
Repository → Service ❌
```

## 包依赖规范

### 包结构

```
com.company.project/
├── api/ # 对外接口（可被其他包依赖）
├── service/ # 业务逻辑（依赖 repository）
├── repository/ # 数据访问（不依赖 service）
└── common/ # 通用组件（被所有包依赖）
```

### 依赖原则

- 高层依赖低层
- 同层不相互依赖
- 依赖接口不依赖实现
