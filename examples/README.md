### Step 1: 选择合适的示例
根据你的需求选择对应的示例：

- 🚀 完整流程演示
- 📊 最终成果
- 🎯 关键要点

1. 创建测试项目
2. 按照示例步骤执行

- 修改需求（如：添加更多字段）
- 尝试不同流程（如：精简流程）
- 增加复杂度（如：添加权限控制）
