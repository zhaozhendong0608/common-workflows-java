## 工作流概览

### 1️⃣ 启动自检 `/boot`
**何时**: 新会话开始、AI 状态重置、切换项目
**输出**: 项目上下文、知识库状态、信心自评

### 2️⃣ 需求雷达 `/radar`

分析需求，自动建议流程类型（精简/标准/完整）。

### 3️⃣ 规约形式化 `/constraint`
**何时**: 每个新需求必须执行
**输出**: 需求分析 + 智能分流建议（ACK-LITE/ACK/ACK-FULL）

### 4️⃣ 受控执行 `/execute`
**何时**: 需求确认后
**输出**: 代码变更 + Evidence Block（分级）

### 5️⃣ 度量分析 `/measure`
**何时**: 标准/完整流程必须，精简流程可跳过
**输出**: KVC/SCV 度量报告

### 6️⃣ 业务测试 `/test`
**何时**: 标准/完整流程必须，精简流程可跳过
**输出**: API/E2E 测试报告

### 7️⃣ 质量关卡 `/quality`
**何时**: 每个任务必须执行
**输出**: 质量审查报告 + 门禁决策（PASS/REJECT）

### 8️⃣ 归档重启 `/archive`
**何时**: 完整流程必须，其他流程可选
**输出**: ADR 决策记录、FAQ 更新、进度同步

## 三种流程模板

### 🟢 精简流程（30分钟）
```
/boot → /radar → /execute → /quality
```

### 🟡 标准流程（60分钟）
```
/boot → /constraint → /radar → /execute → /measure → /test → /quality
```

### 🔴 完整流程（93分钟）
```
/boot → /constraint → /radar → /execute → /measure → /test → /quality → /archive
```
