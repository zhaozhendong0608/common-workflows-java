### 方法 2: 手动归档（传统方式）

**动作**:
1.  **Sync ADR**: 将本次会话产生的 ADR Draft 转正为 `Active`，更新 `project-kernel/03_决策日志 (ADR).md` 索引。
2.  **Sync Landscape**: 若架构有变，更新 `project-kernel/01_项目全景 (Landscape).md`。
3.  **Sync Task**: 更新 `project-kernel/05_项目进度 (Tasks).md` 的状态。
4.  **Sync FAQ**: 识别本次会话中的核心技术见解及 Q&A，沉淀至 `project-kernel/04_答疑库 (FAQ).md`。
5.  **Sync Metrics** ← 新增: 归档度量数据到历史记录。

## Node A.5: 度量数据归档 (Metrics Archiving) ← 新增

**指令**: 将本次开发的度量数据保存到项目历史

### Step 1: 归档度量报告

```bash
# 创建度量归档目录（如果不存在）
mkdir -p .agent/metrics/reports

# 复制本次度量报告
cp .agent/metrics/latest_report.md .agent/metrics/reports/$(date +%Y%m%d)_[任务名称].md

# 示例
cp .agent/metrics/latest_report.md .agent/metrics/reports/20260623_TimeOffsetCmp.md
```

### Step 2: 更新度量历史记录

```bash
# 追加到 CSV 历史文件
echo "2026-06-23,TimeOffsetCmp,1.0,2.0,PASS" >> .agent/metrics/history.csv
```

**CSV 格式说明**:
```csv
date,task,kvc,scv,status
```

**状态说明**:
- `PASS`: KVC >= 0.90 且 SCV < 5.0
- `WARN`: KVC >= 0.90 但 SCV >= 5.0（有警告）
- `FAIL`: KVC < 0.90（未达标）

### Step 3: 生成度量摘要（可选）

```markdown

#### 累计统计（最近 10 次）
```

## 使用技巧

### 快速归档命令（一键执行）

创建脚本 `.agent/scripts/archive.sh`:
```bash
#!/bin/bash
TASK_NAME=$1
KVC=$2
SCV=$3
STATUS=$4

DATE=$(date +%Y-%m-%d)
REPORT_NAME="${DATE}_${TASK_NAME}"

# 1. 归档报告
if [ -f ".agent/metrics/latest_report.md" ]; then
    cp .agent/metrics/latest_report.md ".agent/metrics/reports/${REPORT_NAME}.md"
    echo "✅ 报告已归档: reports/${REPORT_NAME}.md"
fi

# 2. 更新历史
echo "${DATE},${TASK_NAME},${KVC},${SCV},${STATUS}" >> .agent/metrics/history.csv
echo "✅ 历史记录已更新"

# 3. 生成摘要
echo "### 📊 度量摘要 - ${TASK_NAME}"
echo "- KVC: ${KVC}"
echo "- SCV: ${SCV}"
echo "- 状态: ${STATUS}"
```

使用：
```bash
bash .agent/scripts/archive.sh TimeOffsetCmp 1.0 2.0 PASS
```

### 度量趋势可视化（可选）

创建 Python 脚本 `.agent/scripts/plot_metrics.py`:
```python
#!/usr/bin/env python3
import pandas as pd
import matplotlib.pyplot as plt

# 读取历史数据
df = pd.read_csv('.agent/metrics/history.csv')
df['date'] = pd.to_datetime(df['date'])

# 创建图表
fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(12, 8))

# KVC 趋势
ax1.plot(df['date'], df['kvc'], marker='o', label='KVC')
ax1.axhline(y=0.90, color='r', linestyle='--', label='阈值 0.90')
ax1.set_ylabel('KVC')
ax1.set_title('键值一致性趋势')
ax1.legend()
ax1.grid(True)

# SCV 趋势
ax2.plot(df['date'], df['scv'], marker='s', label='SCV', color='orange')
ax2.axhline(y=5.0, color='r', linestyle='--', label='阈值 5.0')
ax2.set_ylabel('SCV')
ax2.set_xlabel('日期')
ax2.set_title('复杂度变化趋势')
ax2.legend()
ax2.grid(True)

plt.tight_layout()
plt.savefig('.agent/metrics/trend.png')
print("✅ 趋势图已生成: .agent/metrics/trend.png")
```

使用：
```bash
python3 .agent/scripts/plot_metrics.py
```

## 常见问题

**Q: 度量数据归档有什么用？**
A: 
1. 追踪项目质量趋势
2. 识别高风险模块（复杂度持续上升）
3. 团队复盘的数据支持
4. 技术债务量化

**Q: 历史数据如何分析？**
A: 使用 Excel 或 Python 生成趋势图，关注：
- KVC/SCV 的移动平均线
- 异常点（突然下降或上升）
- 长期趋势（是否持续恶化）

**Q: 如果度量数据一直不达标怎么办？**
A: 
1. 短期：每次返工修正
2. 中期：培训团队规范意识
3. 长期：考虑 Level 2 自动化检查
