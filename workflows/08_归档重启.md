# 归档重启

**命令**: `/archive`

---

## 输入

- 完成的代码变更
- 质量关卡报告
- 本次会话的技术决策

---

## 核心步骤

### 1. 记录 ADR（架构决策）

**何时需要**:
- 引入新技术栈
- 架构重大变更
- 性能优化方案选择
- 第三方库选型

**ADR 模板**:
```markdown
# ADR-{编号}: {决策标题}

日期: 2026-06-23
状态: 已接受

## 背景
为什么需要做这个决策？

## 决策
我们决定采用什么方案？

## 后果
这个决策的影响是什么？
```

保存到: `project-kernel/03_决策日志/ADR-{编号}.md`

📖 [查看完整 ADR 模板](../templates/adr-template.md)

---

### 2. 更新 FAQ

**何时需要**:
- 遇到了坑或特殊问题
- 有值得记录的经验教训
- 新人可能遇到的问题

**FAQ 格式**:
```markdown
### Q: {问题}
**A**: {答案}

**相关**: ADR-{编号}, {文件路径}
```

保存到: `project-kernel/04_答疑库.md`

---

### 3. 更新项目进度

```markdown
## 2026-06-23
- ✅ 完成用户导出功能
- ✅ 添加 Caffeine 缓存
- ⏳ 待优化：报表性能
```

保存到: `project-kernel/05_项目进度.md`

---

### 4. 自动归档（推荐）

**使用自动归档脚本**:
```bash
# 1. 保存会话内容到 session.log
# 2. 运行归档脚本
python scripts/auto-archive.py

# 输出:
# ✅ 找到 1 个 SQL 脚本
# ✅ 找到 1 处技术讨论
# ✅ 归档完成！
```

**脚本会自动**:
- 提取 SQL 脚本 → `project-kernel/db/migrations/`
- 识别技术讨论 → `project-kernel/03_决策日志/` (ADR 草稿)
- 提取代码片段 → `project-kernel/snippets/`
- 生成会话摘要 → `docs/session_summary_<timestamp>.md`

📖 [查看自动归档使用指南](../docs/自动归档使用指南.md)
