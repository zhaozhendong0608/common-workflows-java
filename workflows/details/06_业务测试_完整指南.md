## API 集成测试

### 测试目标
- 验证 API 接口的正确性
- 测试参数校验、权限校验、异常处理
- 确保响应格式符合规范

### 测试清单

#### 1. 正常场景测试
```bash
# 测试正常请求
curl -X GET "http://localhost:8080/api/users/1" \
  -H "Authorization: Bearer ${TOKEN}"

# 期望响应
HTTP/1.1 200 OK
Content-Type: application/json
{
  "code": 0,
  "msg": "success",
  "data": {
    "id": 1,
    "name": "张三",
    "email": "zhangsan@example.com"
  }
}
```

#### 2. 参数校验测试
```bash
# 测试无效参数
curl -X GET "http://localhost:8080/api/users/invalid" \
  -H "Authorization: Bearer ${TOKEN}"

# 期望响应
HTTP/1.1 400 Bad Request
{
  "code": 400,
  "msg": "参数格式错误：用户ID必须为数字"
}
```

#### 3. 权限校验测试
```bash
# 测试无权限访问
curl -X GET "http://localhost:8080/api/users/1"

# 期望响应
HTTP/1.1 401 Unauthorized
{
  "code": 401,
  "msg": "未登录或登录已过期"
}

# 测试无权限操作
curl -X DELETE "http://localhost:8080/api/users/1" \
  -H "Authorization: Bearer ${USER_TOKEN}"

# 期望响应
HTTP/1.1 403 Forbidden
{
  "code": 403,
  "msg": "无权限执行此操作"
}
```

#### 4. 异常处理测试
```bash
# 测试资源不存在
curl -X GET "http://localhost:8080/api/users/999999" \
  -H "Authorization: Bearer ${TOKEN}"

# 期望响应
HTTP/1.1 404 Not Found
{
  "code": 404,
  "msg": "用户不存在"
}

# 测试服务器错误
curl -X POST "http://localhost:8080/api/users" \
  -H "Content-Type: application/json" \
  -d '{"name":"", "email":"invalid"}' \
  -H "Authorization: Bearer ${TOKEN}"

# 期望响应
HTTP/1.1 500 Internal Server Error
{
  "code": 500,
  "msg": "服务器内部错误"
}
```

### 使用 Spring Boot Test

```java
@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
@AutoConfigureMockMvc
class UserControllerTest {

    @Autowired
    private MockMvc mockMvc;

    @Test
    void testGetUser_Success() throws Exception {
        mockMvc.perform(get("/api/users/1")
                .header("Authorization", "Bearer " + token))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.code").value(0))
                .andExpect(jsonPath("$.data.id").value(1))
                .andExpect(jsonPath("$.data.name").value("张三"));
    }

    @Test
    void testGetUser_NotFound() throws Exception {
        mockMvc.perform(get("/api/users/999999")
                .header("Authorization", "Bearer " + token))
                .andExpect(status().isNotFound())
                .andExpect(jsonPath("$.code").value(404));
    }

    @Test
    void testGetUser_Unauthorized() throws Exception {
        mockMvc.perform(get("/api/users/1"))
                .andExpect(status().isUnauthorized())
                .andExpect(jsonPath("$.code").value(401));
    }
}
```

## E2E 端到端测试

### 测试目标
- 验证完整业务流程
- 测试前端 → 后端 → 数据库 → 前端的数据流转
- 确保用户体验符合预期

### 测试场景

#### 场景1: 用户登录流程

```javascript
// 使用 Cypress
describe('用户登录流程', () => {
  it('正常登录', () => {
    // 访问登录页
    cy.visit('http://localhost:8080/login')
    
    // 输入用户名和密码
    cy.get('#username').type('admin')
    cy.get('#password').type('password123')
    
    // 点击登录按钮
    cy.get('#loginBtn').click()
    
    // 验证跳转到首页
    cy.url().should('include', '/dashboard')
    
    // 验证用户信息显示
    cy.get('.user-info').should('contain', 'admin')
  })

  it('密码错误', () => {
    cy.visit('http://localhost:8080/login')
    cy.get('#username').type('admin')
    cy.get('#password').type('wrongpassword')
    cy.get('#loginBtn').click()
    
    // 验证错误提示
    cy.get('.error-message').should('contain', '用户名或密码错误')
  })
})
```

#### 场景2: 创建用户流程

```javascript
describe('创建用户流程', () => {
  beforeEach(() => {
    // 先登录
    cy.login('admin', 'password123')
  })

  it('成功创建用户', () => {
    // 进入用户管理页面
    cy.visit('http://localhost:8080/users')
    
    // 点击"新增用户"按钮
    cy.get('#addUserBtn').click()
    
    // 填写表单
    cy.get('#name').type('李四')
    cy.get('#email').type('lisi@example.com')
    cy.get('#role').select('user')
    
    // 提交表单
    cy.get('#submitBtn').click()
    
    // 验证成功提示
    cy.get('.success-message').should('contain', '创建成功')
    
    // 验证用户列表中出现新用户
    cy.get('.user-list').should('contain', '李四')
    cy.get('.user-list').should('contain', 'lisi@example.com')
  })
})
```

### 使用 Selenium（Java）

```java
@Test
public void testUserLoginFlow() {
    WebDriver driver = new ChromeDriver();
    
    try {
        // 访问登录页
        driver.get("http://localhost:8080/login");
        
        // 输入用户名和密码
        driver.findElement(By.id("username")).sendKeys("admin");
        driver.findElement(By.id("password")).sendKeys("password123");
        
        // 点击登录按钮
        driver.findElement(By.id("loginBtn")).click();
        
        // 等待页面跳转
        WebDriverWait wait = new WebDriverWait(driver, 10);
        wait.until(ExpectedConditions.urlContains("/dashboard"));
        
        // 验证用户信息显示
        String userInfo = driver.findElement(By.className("user-info")).getText();
        assertTrue(userInfo.contains("admin"));
        
    } finally {
        driver.quit();
    }
}
```

- [ ] 分页功能正常

1. **Postman**
   - 可视化界面
   - 支持环境变量
   - 可生成测试代码

   - 命令行工具

   - 自动回滚数据库

   - 自动等待

## 常见问题

### Q1: API 测试覆盖率要多少？

**A**: 
- 精简流程: 跳过 API 测试，只做单元测试
- 标准流程: API 测试覆盖核心场景（正常+异常）
- 完整流程: API 测试覆盖所有场景（包括边界条件）

### Q2: E2E 测试太慢怎么办？

**A**:
- 只测试关键业务流程
- 使用 headless 模式（无界面）
- 并行执行测试
- 定期执行，不是每次提交都跑

### Q3: UI 测试是否必须？

**A**:
- 精简/标准流程: 可跳过
- 完整流程: 必须执行，确保用户体验
- 建议：重要功能发布前必须手动测试

### Q4: 测试环境如何准备？

**A**:
```bash
# 1. 启动测试数据库
docker run -d -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=test \
  -e MYSQL_DATABASE=test_db \
  mysql:8.0

# 2. 启动应用（测试环境）
mvn spring-boot:run -Dspring.profiles.active=test

# 3. 运行测试
mvn test
```

### Q5: 如何处理测试数据？

**A**:
- 使用 @Transactional 自动回滚
- 使用 H2 内存数据库
- 每次测试前清理数据
- 使用测试数据工厂（Fixture）
