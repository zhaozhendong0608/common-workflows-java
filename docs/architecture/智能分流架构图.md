sequenceDiagram
    participant U as 用户

    AI->>U: 展示评估结果<br/>+ 流程建议<br/>+ 预计时间
    
    U->>AI: ACK-LITE / ACK / ACK-FULL
    
    alt 精简流程
        AI->>W: 启动精简流程
        W->>W: 04_受控执行
        W->>W: 07_质量关卡
        W-->>AI: 简化 Evidence (5字段)
    else 标准流程
        AI->>W: 启动标准流程
        W->>W: 03_规约形式化
        W->>W: 04_受控执行
        W->>W: 05_度量分析
        W->>W: 07_质量关卡
        W-->>AI: 标准 Evidence (8字段)
    else 完整流程

        W-->>AI: 完整 Evidence (23字段)
    end
    
    AI->>U: 交付成果<br/>+ Evidence Block
    U->>AI: 确认完成
