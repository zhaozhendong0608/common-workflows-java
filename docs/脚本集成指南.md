# 脚本集成到工作流指南

本文档说明如何在工作流中使用自动化脚本。

## 📊 脚本与工作流的对应关系

| 脚本 | 工作流阶段 | 调用时机 | 作用 |
|------|-----------|---------|------|
| `constraint-check.sh` | 04_受控执行 | 代码完成后 | 检查约束合规性 |
| `metrics.py` | 05_度量分析 | 执行度量分析时 | 计算 KVC/SCV |
| `evidence-gen.sh` | 04_受控执行 | 生成 Evidence 时 | 生成 Evidence Block |

## 💡 使用方式

### 方式 1: 手动调用（推荐）

**在工作流执行到对应阶段时，手动运行脚本**：

```bash
# Step 4: 受控执行完成后
./scripts/constraint-check.sh .
./scripts/evidence-gen.sh standard > .agent/evidence.md

# Step 5: 度量分析
python scripts/metrics.py .
```

**优势**:
- ✅ 灵活：可以根据需要选择性执行
- ✅ 可见：清楚看到每个脚本的输出
- ✅ 可控：遇到问题可以及时调整

---

### 方式 2: 集成到 Git Hooks（自动化）

**在 Git 提交前自动检查**：

```bash
# 创建 pre-commit hook
cat > .git/hooks/pre-commit << 'EOF'
#!/bin/bash
echo "🔍 执行约束检查..."
./scripts/constraint-check.sh . || exit 1
echo "✅ 约束检查通过"
EOF

chmod +x .git/hooks/pre-commit
```

**优势**:
- ✅ 自动化：提交前自动检查
- ✅ 防御：阻止不合规代码提交
- ✅ 团队：统一质量标准

---

### 方式 3: 集成到 CI/CD（持续集成）

**在 GitHub Actions / GitLab CI 中自动执行**：

```yaml
# .github/workflows/quality-check.yml
name: Quality Check

on: [push, pull_request]

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      
      - name: Setup Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.9'
      
      - name: Install dependencies
        run: pip install radon lizard
      
      - name: Constraint Check
        run: ./scripts/constraint-check.sh .
      
      - name: Metrics Analysis
        run: python scripts/metrics.py .
      
      - name: Upload Reports
        uses: actions/upload-artifact@v2
        with:
          name: metrics-reports
          path: .agent/metrics/
```

**优势**:
- ✅ 全自动：每次推送/PR 自动执行
- ✅ 团队可见：结果在 CI 面板展示
- ✅ 持续追踪：度量数据持续积累

## 🔧 故障排查

### 脚本执行失败

**问题**: `./scripts/constraint-check.sh: Permission denied`

**解决**:
```bash
chmod +x scripts/*.sh
```

---

**问题**: `python: command not found`

**解决**:
```bash
# macOS/Linux
python3 scripts/metrics.py .

# 或创建别名
alias python=python3
```

---

**问题**: `ModuleNotFoundError: No module named 'radon'`

**解决**:
```bash
pip install radon lizard
```
