## 🔄 文档维护

### 新增文档规则

1. **确定分类**: 选择合适的子目录
   - `architecture/` - 架构设计类
   - `releases/` - 版本发布类
   - 如需新分类，先讨论再创建

2. **命名规范**:
   - 版本报告: `vX.Y.Z_改进报告.md`
   - 架构文档: `系统名称架构图.md`
   - 使用中文命名，清晰易懂

3. **更新索引**: 在对应子目录的 README.md 中添加文档说明

### 更新频率

- **architecture/** - 架构重大变更时更新
- **releases/** - 每次版本发布时新增报告
